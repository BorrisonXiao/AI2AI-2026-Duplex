Experiments

Background reasoning in a full-duplex loop.

The current experiment follows a math request from S1’s recognition and THINK signal through S2’s computation to the spoken answer.

S2 math: seventeen times twenty-three

Model-triggered S2

Compute 17 × 23 and speak 391

S1 acknowledges the request while the separate S2 model reasons. S2 returns 391 in 1.359 seconds; its completed guidance reaches S1 at tick 11, followed by “The result is 391.”

2 × H100 SXM, 80 GB each · complete S1 stack on GPU 0 · S2 on GPU 1 · maximum two GPUs active. Calibration precedes the math request.

How this fits the project

The experiment exercises asynchronous reasoning and result delivery while the interaction loop keeps running. It provides a working component for the broader goal of coordinating multi-speaker conversation, tool calling, and a learned policy for when to act.

See the S1–S2 information exchange for the model interface, the benchmark tabs for evaluation protocols, and the AMI text-question method for requests grounded in earlier meeting history.
