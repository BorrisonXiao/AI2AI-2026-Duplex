The model-triggered calculation

The user says “Please calculate seventeen times twenty-three.” S1 transcribes the request and emits its own [THINK] at tick 7. The controller sends S1’s actual accumulated user transcription to Qwen3-4B-Thinking-2507.

S2 completes in 1.359 seconds, using 296 completion tokens, and returns 391. The controller delivers that plain text in from_s2 at tick 11. Independent transcription of played speech reads “Sure, let me work that out. The result is 391.” S1’s initial acknowledgment overlaps the active S2 request.

A human question with explicit delegation

A DailyTalk human recording asks about the difference between an outlet and a regular store. This condition forces one S2 dispatch. S2 uses the dialogue context accumulated from S1’s user transcription and assistant words.

S2 returns its complete discount/full-price clause in 1.536 seconds using 336 completion tokens. The clause reaches S1 at tick 14. Actual played speech is transcribed as “An outlet is a store that sells discounted items, a regular store sells products at full price.” S1 processes three more audio packets during S2’s request, and speech overlaps that request for about 1.05 seconds.

Models, scheduling and resources

Each full handoff run uses 2 × H100 SXM 80 GB. GPU 0 hosts the complete S1 stack: Thinker, Talker, MTP and Code2Wav. GPU 1 hosts Qwen3-4B-Thinking-2507 alone. Both services are loaded before a known-question calibration checks S1 and speech request times with S2 idle and under load; the handoff examples follow that calibration. Runs are sequential, with a maximum of two GPUs active.
