The model-triggered calculation

The user says “Please calculate seventeen times twenty-three.” S1 transcribes the request and emits its own [THINK] at tick 7. The controller sends S1’s actual accumulated user transcription to Qwen3-4B-Thinking-2507.

S2 completes in 1.359 seconds, using 296 completion tokens, and returns 391. The controller delivers that plain text in from_s2 at tick 11. Independent transcription of played speech reads “Sure, let me work that out. The result is 391.” S1’s initial acknowledgment overlaps the active S2 request.

Models, scheduling and resources

The experiment uses 2 × H100 SXM 80 GB. GPU 0 hosts the complete S1 stack: Thinker, Talker, MTP and Code2Wav. GPU 1 hosts Qwen3-4B-Thinking-2507 alone. Both services load before a latency calibration checks S1 and speech requests with S2 idle and under load. The math experiment follows this calibration, with a maximum of two GPUs active and no overlapping experiment job.

From S1’s words to S2’s prompt

S1’s asr values through tick 7 assemble into “Please calculate 17 times 23.” At tick 7, S1 also emits system2_control: "[THINK]". The controller uses the recorded user_only context policy to send S2 its system instruction and the accumulated recognized request. S1’s acknowledgment and control fields stay in the interaction loop.

Complete prompt sent to S2 · system and user messages

The two role/content messages below are the complete chat input saved at dispatch. The system instruction comes from the controller configuration; S1 supplies the recognized request. Unicode escapes represent the original command delimiters. The local S2 server applies the model’s chat template to these messages; its usage record reports 105 prompt tokens.

[
  {
    "role": "system",
    "content": "You are System 2 helping a voice assistant answer the latest complete user request. Work it out privately, then give one concise final answer in English, at most 25 words. Enclose the complete answer in \u3010 and \u3011. For arithmetic, give the calculation and its result. Use User text as the request; Agent text is only context. Do not greet or invent access to tools."
  },
  {
    "role": "user",
    "content": "Please calculate 17 times 23."
  }
]

How the result returns to speech

S2’s final-content field is "\n\n\u3010391\u3011". The controller extracts the completed clause, removes the command delimiters, and supplies "391" in S1’s from_s2 input at tick 11. S1 then emits "The result ", "is ", and "391." at ticks 11–13.
