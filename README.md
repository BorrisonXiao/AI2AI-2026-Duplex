# AI2AI 2026 · Duplex

Website for this repository: [AI2AI 2026 Duplex](https://borrisonxiao.github.io/AI2AI-2026-Duplex/index.html). GitHub Actions deploys the `main` branch through the Deploy report workflow.

DuplexOmni architecture, selected successful speech and reasoning reproductions, five speech benchmark guides, and the AMI text-question method.

The site is static HTML, CSS and JavaScript. Serve this directory with `python -m http.server 8000` for a local preview. Third-party audio and templates retain their source attribution and licenses.
