Can earlier thinking shorten answering?

We compare what a thinker saves while listening, then measure answer quality and the work left after a question.

We fix update times to study what to save.

Can short, useful results saved before a request improve the answer and reduce request-time thinking?

Reactive

Process the available history and reason when the question arrives.

Amortized

Also generate saved notes before the question, then include one current view in the final call.

  • Speech is grouped into meaningful 10–40 second segments; brief fillers alone do not trigger a new update.
  • Detailed notes update on the fixed segment schedule; overviews update every 2, 4 or 8 processed segments.
  • Final answers retain the available original history in every matched condition.

The same history and request define each comparison.

The completed evaluation contains 105 questions from 26 conversations: 93 AMI meeting questions and 12 earnings-call questions. Each question has a source-based reference answer.

Text thinkers receive the transcript plus one chosen view.

Both text backbones see the full past speaker-labelled reference transcript and the request. A common Qwen3 Instruct writer generates notes before the request; the conditions change which saved view is supplied.

Source quotes copy passages selected by earlier note evidence IDs; those passages already occur in the full transcript. Selection never uses the future question. Quotes + earlier evidence also follows earlier versions of still-active notes.

Audio thinkers receive speech and optional labelled voice examples.

Each audio backbone receives the original past recording and the spoken request. Its saved notes are generated from earlier audio. Reference transcripts and question text are used for evaluation only.

Labelled examples explicitly provide the reference speaker identities using speech already heard before the question; audio alone has no A–D identity guide. Voice-overview entries describe audible delivery or tentative affect; names and relationships require evidence in speech.

Function calls edit one current note state.

  1. The writer receives new transcript or audio, current notes and recent context; the question is unavailable.
  2. The model emits a local function call with changed fields and source IDs.
  3. The program validates the call, applies accepted edits and retains earlier versions.
  4. The final thinker receives one current view plus the original history when the request arrives.

The full evaluation shows no uniform answer-time gain.

  • Text saved views change accuracy modestly; mean thinking savings vary across questions.
  • Qwen audio notes increase first-answer time in both speaker conditions.
  • Earlier writing adds generation cost even when a final answer uses fewer thinking tokens.

Evaluation protocol
  • The reference checklist specifies the facts the request requires; the available past transcript verifies both those facts and extra claims.
  • A fully supported answer supplies the required facts and makes no material unsupported addition.
  • The local Qwen3-30B judge receives the question, candidate, reference checklist and past transcript; its labels are corrected by source review where inspected.
  • Request-time thinking counts native reasoning tokens after the question; earlier note and overview tokens are counted separately.
  • First-text time starts at the question-time model call and ends when answer text begins; audio preprocessing is included.
  • Full available history is retained when it fits; two long MiniCPM cases use the same shorter history in every matched condition.
  • This study evaluates note content with causal source cutoffs; real-time completion of earlier writing remains a later test.

One audio overview saves request-time work at higher total cost.

The overview pilot evaluates eight AMI questions from five meetings; all 608 condition and input-order records were source-checked. Overviews cover topics, topics plus speakers, or—only for audio—topics, speakers and voice delivery, at 2-, 4- or 8-segment intervals.

  • Qwen audio alone: function notes and the four-segment topic/speaker/voice overview support the same seven answers.
  • That overview reduces thinking by 17.2% and first-text time from 11.00 to 9.62 seconds; complete generation increases by 34.3%.
  • Reactive is faster at 4.78 seconds, with six of eight supported answers.

How the pilot labels and input order are interpreted

The current text pilot puts the request last, after the transcript and saved views. The original overview-last control retains identical saved content; its apparent token saving did not persist after reordering. The pilot consistently applies the frozen poster checklist, including the half-day allocation; two reused count-only answer labels were corrected within this pilot. The earlier full-set records remain unchanged.

Useful saved evidence matters more than additional description.

  • Original source quotes can recover information that generated note text loses or misstates.
  • Broad overviews can inherit wrong speaker ownership or mistake room-related small talk for the meeting’s main topic.
  • The audio pilot provides a candidate request-time saving; full-set confirmation and complete-cost accounting remain necessary.

Next: improve source support for topic and speaker updates, diagnose corrupted audio-model outputs, then freeze the recipe and test the new overview settings on all 105 questions.
